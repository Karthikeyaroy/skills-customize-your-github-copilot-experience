# Assignment Structure Skill

This skill provides instructions for writing and formatting assignment markdown files in this repository.

## Goal

Ensure assignment README files use a consistent structure, clear objectives, and measurable task requirements.

## Instructions

- Use the project template located at `templates/assignment-template.md`.
- Create each assignment as a `README.md` inside its assignment folder under `assignments/`.
- Keep the structure and icons exactly as shown in the template:
  - `# 📘 Assignment: <Title>`
  - `## 🎯 Objective`
  - `## 📝 Tasks`
  - `### 🛠️ <Task Title>`
  - `#### Description`
  - `#### Requirements`
- Write a concise objective describing what the student will learn or build.
- For each task, list concrete expected outcomes using bullet points.
- Avoid extra sections unless the project explicitly requires them.
- Use example input/output in code blocks only when it helps clarify the requirement.
